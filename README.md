# GLOSSBRO Automechanika tablet catalogue

Single-file, tablet-first product catalogue for the GLOSSBRO booth. Open `index.html` in a modern browser to use it.

## Content workflow before the show

1. Replace the shared video ID in `officialVideo` with each product's approved GLOSSBRO/authorised-detailer YouTube clip.
2. Replace each card thumbnail with an approved frame from that clip.
3. Have a German-speaking teammate confirm all German copy, claims, and before/after material.

The product names used in the initial catalogue are based on the official GLOSSBRO English catalogue. The set intentionally contains no price or unverified performance claims, making it safer for initial distributor conversations.
